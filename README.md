# Geronfir

**Android-only developer** — I build, test, and ship real software from a phone. No laptop, no PC.

I develop entirely on an Android phone: a full Linux environment via **Termux + proot (Debian)**, **tmux** for a persistent workspace, and **GitHub Actions as my build machine**. Everything below was written, compiled, and released from that phone.

Constraints force discipline: no desktop IDE means scripted, reproducible builds; no fast CPU means lean, efficient code. I ship anyway.

### Featured

- **[word-clock-widget](https://github.com/Geronfir/word-clock-widget)** — Android home-screen widget that spells the time in words. Pure-Kotlin, fully unit-tested engine. Built & released via CI.
- **[termux-workstation](https://github.com/Geronfir/termux-workstation)** — how I turned Android into a real dev box: tmux, proot, shell tooling, a local LLM, and CI. Config + docs.
