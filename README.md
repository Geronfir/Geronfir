**Android (Kotlin) + Linux-tooling developer — I build, test and ship real software from an Android phone.** No laptop, no PC.

I develop entirely on an Android phone: a full Linux environment via **Termux + proot (Debian)**, a persistent **tmux** workspace, and **GitHub Actions as my build machine**. Everything below was written, compiled, tested and released from that device.

Constraints force discipline — no desktop IDE means scripted, reproducible builds; a small CPU and tight RAM mean lean, deliberate code. I ship anyway.

---

### Featured work

**[word-clock-widget](https://github.com/Geronfir/word-clock-widget)** — Android home-screen widget that spells the time in words. The time-to-words engine is pure Kotlin with **no Android imports**, so all **71 unit tests run on a plain JVM** in CI. Jetpack Glance, offline-first, no background service.

**[termux-workstation](https://github.com/Geronfir/termux-workstation)** — how I turned an Android phone into a real dev box: tmux sessions that survive app restarts, a Debian userland via proot, shell tooling that pushes build results to the phone, and CI as the build machine. Docs + sanitized configs.

**[geronfir.github.io](https://geronfir.github.io)** — portfolio with case studies for the projects above.
